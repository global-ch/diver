# Contributing to Diver

Thank you for your interest in contributing to the Diver project! We welcome all contributions from the community, whether they're improvements to documentation, new content, bug fixes, or suggestions for enhancement.

## How to Contribute

### Reporting Issues
If you find an issue or have a suggestion, please open a GitHub issue with:
- A clear title describing the problem or suggestion
- Detailed description of what you found
- Any relevant examples or screenshots
- Steps to reproduce (if applicable)

### Submitting Content
We welcome new content related to scuba diving! You can contribute by:
- Adding new guides or tutorials
- Improving existing content
- Sharing dive site information
- Contributing safety tips and best practices
- Translating content to other languages

### Making Changes
1. Fork the repository
2. Create a new branch for your changes (`git checkout -b feature/your-feature`)
3. Make your improvements
4. Test your changes thoroughly
5. Commit with clear messages (`git commit -m 'Add detailed commit message'`)
6. Push to your branch (`git push origin feature/your-feature`)
7. Open a Pull Request with a description of your changes

## Pull Request Process
- Clearly describe what changes you've made and why
- Reference any related issues
- Keep your PR focused on a single topic
- Be open to feedback and discussion
- Help maintain the quality and accuracy of content

## Content Guidelines
- Keep content clear and accessible to divers of all levels
- Verify information for accuracy, especially safety-related content
- Use proper markdown formatting
- Include citations for technical information
- Maintain a friendly and encouraging tone

## Code of Conduct
Be respectful and constructive in all interactions. We value diverse perspectives and welcome everyone to participate.

## Questions?
Feel free to open an issue for any questions about contributing. We're here to help!
